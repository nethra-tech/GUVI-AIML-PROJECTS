# Google Pay Expense Sharing

## About
Google Pay Expense Sharing is a simple Python project that helps friends manage and share their expenses.

## Features
- Add and view friends
- Add shared expenses
- Equal and custom expense splitting
- View all expenses
- View individual transaction history
- Display balance summary
- Suggest payments
- Record settlement payments

## Technologies Used
- Python
- SQLite
- PrettyTable
- Jupyter Notebook

## Installation

Install the required library:

```bash
pip install -r requirements.txt
```

## How to Run

1. Download or clone this repository.
2. Open the Jupyter Notebook.
3. Run all cells.
4. Use the menu to manage friends and expenses.

## Database
SQLite stores friends, expenses, expense shares and settlement records.
